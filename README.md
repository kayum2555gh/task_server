# MERN Stack Todo App

A full-stack Todo application built using the MERN stack as part of my journey in learning web development. This project helped me gain practical experience in frontend development, backend API integration, and database management.

### 🛠️ Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **API Integration:** Axios

### ✨ Key Features

* Create and manage todo tasks.
* Integrate frontend components with backend APIs.
* Store and retrieve task data using MongoDB.
* Handle HTTP requests using Axios.

### 📚 Key Learnings

* Building REST APIs using Node.js and Express.js.
* Connecting React with a MongoDB-backed backend.
* Understanding CRUD operations and full-stack application architecture.

### 🎯 Purpose

Built as a hands-on learning project to strengthen my MERN stack development skills and gain practical experience in building full-stack web applications.
